## 禁止事項
- 禁止使用 Inter、Roboto、Arial、system-ui 字體
- 禁止紫色漸層背景
- 禁止 emoji 堆疊作為視覺裝飾
- 禁止對稱 card grid 搭配等距 padding

## 字體規範
- Display: Sora 或 Cabinet Grotesk
- Body: DM Sans

## 元件規則
- 按鈕文案：動詞開頭，最多 3 個字
- 錯誤提示：說明原因 + 解決方法
